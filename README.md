# simpleVoiceover

Настольная студия озвучки для Windows: Tauri/WebView2, React и Rust. Окно приложения управляет жизненным циклом движка; отдельный CMD не нужен. FFmpeg и внешние медиасервисы не используются.

## Запуск и сборка

Исходники: `/home/arcon/dev/my/tools/simpleVoiceover` в Ubuntu-26.04. Исполняемый файл: `D:\devw\my\tools\simpleVoiceover\simpleVoiceover.exe`.

```bash
svoice start
svoice status
svoice logs
svoice stop
svoice help
```

`stop` запрашивает обычное закрытие окна. Если есть изменения, выбери в приложении: сохранить, закрыть без сохранения или отменить. Во время записи и файловой операции закрытие блокируется. После закрытия окна встроенный HTTP-сервер и аудиоканал завершаются.

Сборка Windows из WSL:

```bash
bin/build-windows
```

Нужны Node.js, Rust, установленный target `x86_64-pc-windows-msvc`, cargo-xwin и LLVM resource compiler `llvm-rc`. Скрипт использует установленный LLVM либо локальный комплект `.build-tools/llvm`. На Windows требуется WebView2 Runtime. При обновлении исполняемый файл не должен быть запущен.

## Работа с проектом

Верхние действия находятся в попапе бургера слева: импорт, открытие, сохранение, рабочий каталог, экспорт и справка. Между видео и дорожками граница 8 px; управление записью и воспроизведением находится поверх нижнего края предпросмотра.

Медиа добавляются нативным диалогом или перетаскиванием файлов. Rust читает локальный диск напрямую, без загрузки через WSL. Лимит исходного файла — 100 000 000 000 байт. Декодирование, форма волны, эффекты, монтаж и экспорт выполняются в Rust; большие медиа обрабатываются потоково. Распакованное PCM-аудио может занимать больше места, чем исходник.

Поддерживаются аудиокодеки Symphonia, включая AAC-LC, MP3, WAV, FLAC, ALAC и Vorbis. Opus пока не поддерживается. Видео показывается WebView2 в исходном формате: поддержка изображения зависит от его кодека. Видео без декодируемой аудиодорожки не импортируется. Экспортируется аудио, а не новое видео.

Один выбранный микрофон может быть вооружён только на одной аудиодорожке. Запись начинается с позиции курсора, другие дорожки продолжают играть. Завершение записи останавливает воспроизведение. Исходный дубль хранится без эффектов; обработка применяется при прослушивании и экспорте.

Lock защищает редактирование клипов, но позволяет запись, микшер и эффекты. Mute влияет на воспроизведение; записываемый сигнал не заглушается. Ножницы разрезают в точке клика или позиции курсора с точностью одного сэмпла 48 кГц. Центральная часть нижнего бегунка перемещает viewport, края меняют масштаб. Минимальная ширина бегунка — 60 px.

## Сохранение и кэш

`.justspeak` — один переносимый ZIP64-файл без сжатия, включающий исходные медиа, записи, PCM-кэш, форму волны, монтаж и настройки дорожек.

- До первого сохранения кэш находится в выбранном рабочем каталоге; по умолчанию `%TEMP%\simpleVoiceover`.
- После сохранения изменения создают каталог `.simpleVoiceover-<UUID>` рядом с файлом проекта.
- Ctrl+S упаковывает кэш в проект, атомарно заменяет сохранённый файл и удаляет отдельный каталог кэша. Также очищает Undo и Redo.
- Чистый проект воспроизводится и экспортируется прямо из ZIP64: отдельный кэш для этого не распаковывается.
- Следующее редактирование снова материализует кэш рядом с проектом.
- Незавершённая сессия восстанавливается при запуске. «Закрыть без сохранения» отбрасывает её изменения и удаляет принадлежащий ей временный кэш.

## Экспорт и эффекты

Каждую дорожку или весь микс можно сохранить через нативный диалог в WAV или MP3. WAV: stereo PCM 16 bit, 48 кГц; большие файлы используют RF64. MP3: stereo 256 кбит/с, 48 кГц, Rust-кодер shine-rs. Индивидуальный экспорт игнорирует mute/solo и сохраняет начальную тишину для совмещения; экспорт микса учитывает mute/solo. Оба применяют монтаж, эффекты, громкость и панораму.

Пресет «Естественный войс» регулируется: high-pass 70 Гц, EQ 250 Гц −1,5 дБ, presence 3200 Гц +1 дБ, low-pass 15 кГц, компрессия −24 дБ / 2,3:1, атака 12 мс, восстановление 160 мс, усиление +2,9 дБ. Мягкий экспандер приглушает тихие участки без удаления времени; по умолчанию приглушение выключено. Whisper и спектральное шумоподавление не используются.

## Клавиши

| Клавиши               | Действие                  |
| --------------------- | ------------------------- |
| Space                 | Воспроизведение / пауза   |
| R                     | Начать / завершить запись |
| V / X                 | Стрелка / ножницы         |
| Delete                | Удалить выделенный клип   |
| Home                  | К началу                  |
| Ctrl+S / Ctrl+Shift+S | Сохранить / сохранить как |
| Ctrl+Z / Ctrl+Shift+Z | Undo / Redo               |

## Архитектура и проверки

React-компоненты находятся в `src/components`, интерфейс таймлайна — в `src/timeline`. Hooks отделяют транспорт, горячие клавиши, нативный drag-drop и закрытие окна. `StudioClient` вызывает Tauri commands и принимает events; бинарный WebSocket передаёт только PCM, микрофон и подтверждения доставки. AudioWorklet выполняет физический захват и вывод звука, без монтажа или DSP.

Rust разделён на управление командами, монтаж, хранилище, ZIP64-архив, файловые диалоги, декодирование, DSP, микшер, аудиосессию, HTTP/Range и Tauri lifecycle. HTTP API не предоставляет управления проектом.

```bash
npm test
npm run format:check
npm run build
cargo fmt --manifest-path backend/Cargo.toml --check
```

Unit/integration-тесты проверяют точный разрез, эксклюзивный arm, lock/mute, запись и последнюю порцию микрофона, Undo/Redo и очистку истории, перенос кэша и сохранение, чтение архива без распаковки, WAV/MP3 roundtrip, HTTP Range, ограничения origin, WebSocket и физический AudioWorklet I/O. Полный файл размером 100 ГБ пока не использовался для стресс-теста.

Медиабиблиотеки: Symphonia (MPL-2.0), shine-rs (LGPL-2.0), zip (MIT). Точные версии зафиксированы в `backend/Cargo.lock`; зависимости фронта — в `package-lock.json`.
